## 真实浏览器

用 Chrome CDP 在 1360 px 桌面及 390 × 844 px 手机视口检查：

- 首页、登录、名单导入、新建活动、活动切换、学生空间、后台与活动管理，无水平溢出。
- 实际限速网络上传 2 MiB 图片，看到持续变化的字节和百分比，双击提交只产生一件作品，成功后回到查看状态。

- 无未捕获 JavaScript 异常、无 CSP 阻止记录。

## 适用范围

该压测使用本机回环网络、2 MiB 测试图片和开发机磁盘。CPU 配额及内存上限与目标主机留余量的配置一致，CPU 型号、磁盘性能、网络链路与真实 ECS 不同。不能据此保证 81 人从校园网络上传大视频的耗时，或承诺所有网络情况下均无超时。

上线前应备份原数据，按 `MIGRATION.md` 切换，再使用接近实际活动的文件和手机网络复测，观察云带宽、磁盘、页面响应及上传耗时。初始配置允许等待以保护页面；队列容量、磁盘余量或超时达到上限时会返回可重试提示。
